한의학에서 임베딩 모델이 실제 의미보다는 단순 토큰중복에 의존하는 경향이 있는것과, llm의 한의학 국가고시 성능이 낮은 이유가 학습데이터 부족이라는 가천대학교 한의학과(김창업교수님)의 두 연구들을 참고하여, 한의학에서 임베딩 성능 개선 방법론을 탐색하고 임베딩 성능을 개선한 한의학 맞춤 rag를 통해서 방법론을 실험해보고자 합니다. 

대조학습 파인튜닝, 청킹단계에서 요약과 체질메타데이터 추가, 리랭킹, 하이브리드 리트리버 등 시도해보았습니다. 현재 동의수세보원으로 학습한 모델로 사상의학(동의수세보원=사상의학) 국가고시 문제를 풀게하는 실험을 진행했고, 결과는 체질+요약 메타데이터추가, 리랭킹, 하이브리드는 retrieval 단계 평가에서 ablations와 누적 각각 성능 개선이 확인이 되었고, 최종적으로 optimized rag: contextual_ft2+ft1_hybrid_reranked가 가장 좋은 모델로 나왔습니다. (Hit Rate: 0.90, MRR: 0.8417, NDCG: 0.8881 @k=3). 정답 쿼리-document는 직접 한 회의 기출문제들의 정답문서들을 일일이 찾아서 20개정도만 만들어서 실험했습니다. 더 확장할 예정입니다.

Retrieval 벤치마크 중 MLDR과 MIRACL 의 경우 쿼리의 개수가 대략 200개.

그리고 이 모델로 해본 generation 단계 평가에서, 사상의학 국가고시 정답률이 gpt(rag 데이터 안주고 문제만 풀게했을떄) : 28%, base dense : 50%, optimized rag: 53% , 근거명시하라고 한 optimized rag:56%,
상한론 국가고시(학습과 테스트의 데이터셋이 완전히 다른 일반화 테스트)에서는, ft2-ft1(연속파인튜닝): 14/32개 > ft2 (원문-번역) : 12개/32개 > base dense: 9/32개, ft1(합성쿼리):7/32 순서로 나왔고, 가설에서 기대했던 성능 개선이 확인되었습니다.

실험조건은 아래와 같았습니다.
임베딩 모델: e5-small-ko (base dense)
LLM(Generator): GPT-4.1-mini (temperature=0)
청크 크기: 500~700자 (섹션 기반 청킹)
검색기 (Retriever): 초기 k: 5 (리랭킹 시에는 후보군 확보를 위해 10으로 확장)
하이브리드 검색 가중치: BM25 0.5 : Dense 0.5 (실험적으로 도출한 최적값,Hit Rate, MRR, NDCG의 평균으로 평가지표를 냈습니다.)
리랭커 (Reranker):모델: BAAI/bge-reranker-v2-m3 , top_n: 5
파인튜닝 부분 성능개선이 부족한것같아서, 파인튜닝 부분을 좀 개선(데이터확장)하려고합니다.

fp16+ Loss function 이름에서 “[`CachedMultipleNegativesRankingLoss`](https://sbert.net/docs/package_reference/sentence_transformer/losses.html해시태그#cachedmultiplenegativesrankingloss), [`CachedGISTEmbedLoss`](https://sbert.net/docs/package_reference/sentence_transformer/losses.html해시태그#cachedgistembedloss)"와 같이 Cached 라는 단어가 붙은 Loss를 사용해서 mini batch size는 GPU 할당할 수 있는 정도로 작게 설정하고 batch size는 크게. Gradient Accumulation을 사용하는 것보다 Cached 가 붙은 Loss function을 사용하는 것이 in-batch negatives를 좀 더 효과적으로 사용할 수 있다.


- 실험 설계의 강건성
테스트 A (사상의학), In-Domain test: 동의수세보원 + 동의보감으로 학습한 임베딩모델로 RAG에 동의수세보원 원문/동의수세보원 한글판을 제공해서 사상의학 문제 풀이. (학습데이터와 테스트데이터가 일부 겹침, 데이터 유출+ 강건성 문제에 대한 최소한의 조치로 테스트 데이터셋의 정답문서 section들은 학습에서 제외)

테스트 B (상한론), Out-of-Domain test: 동의수세보원 + 동의보감으로 학습한 임베딩모델로 RAG에 상한론 원문/ 상한론 한글판 제공해서 상한론 문제 풀이. (학습데이터와 테스트데이터가 완전히 달라서 일반화 테스트)
여기서 사상의학은 우리나라의 독자적인 부분이라 데이터가 희소하여 동의수세보원을 학습에 사용하되, 데이터 유출을 최소화하기 위해, 동의수세보원의 국시 문제 정답에 해당하는 섹션들은 따로 추출하여 학습에서 제외했습니다.
동의수세보원(사상의학)과 상한론으로 학습데이터를 만들어서 학습시키고, 사상의학 국가고시와 상한론 국가고시로 test를 하면 실험의 강건성 측면에서 좋지 않을 것 같아, 동의보감이라는 한의학 기본도서를 학습데이터로 사용하고, 상한론이라는 새로운 데이터로 테스트 해보려고 했습니다.

- 파인튜닝 학습 전략
파인튜닝을 위해 두 종류의 데이터셋(FT1, FT2)을 생성했습니다. (epochs: int = 3, batch_size: int = 8 로 학습)
FT1: (합성 질문, 문서 청크) - 검색 해결 능력 학습용
FT2: (원문 한문, 번역 한글) - 도메인 언어 및 개념 이해 능력 학습용 (가설- ft2 방식이 한의학의 임베딩 성능 부족을 상승시킬것이다. )
이 두 데이터셋을 학습시키는 방식에 대해 두 가지 전략을 고민 중입니다.
전략 A (연속적 학습): FT2로 먼저 '언어 이해'를 학습시킨 뒤, 이어서 FT1으로 '검색 과제'를 학습
전략 B (통합 학습): FT1과 FT2 데이터를 모두 섞어 한 번에 학습

전략 A의 경우, 2단계에서 FT1을 학습할 때 1단계에서 배운 FT2의 능력을 잊어버리는것, 전략 B는 In-batch Negative 과정에서 우연히 의미가 통하는 (질문, 번역문)이 부정 쌍으로 잘못 학습될 'False Negative' 위험 걱정이 됩니다. (False negative는 데이터가 많아질수록 우연히 맞아떨어지는 경우가 떨어져서 어느정도 무시될 것 같긴 하지만) 

Ft1 질문은 한글 400자~600자 청크에서, 2문제 생성(국가고시 문제와 비슷하게 prompt 입력), FT2 원문-한글 세트는 예를 들어 다음처럼 한 구절들을 세트로 했습니다. 
Generator 평가 (사상의학 국가고시, 상한론 국가고시)에서는 단순 국가고시 정답률 외에, 근거와 근거원문을 추출하게 하여, 정성적 평가와 ragas의 faithfulness 정도만 추출해서 확인해볼 예정입니다. 

실험 세부 가설:
1. FT2 (원문-번역 대조 학습)의 효과 가설: 고전 한문 원문과 한글 번역본 간의 의미적 일치를 학습함으로써, 임베딩 모델이 (단순 번역성능 개선 외에), 한의학 용어 및 개념의 표현 형식이 달라도 동일한 의미를 효과적으로 인지하게 되어, 단순 토큰 중복을 넘어선 의미 기반 검색 능력이 향상될 것이다. ('실제 의미보다 토큰 중복' 문제 해결)

→ 영어와 한글의 임베딩을 가깝게 위치시키는 학습임으로 영어 질문으로 한글 문서 검색과 같은 cross-lingual한 상황에 많이 쓰여왔음. “용어 및 개념의 표현 형식이 달라도 동일한 의미를 효과적으로 인지”하게 하려면 MLM 학습을 진행해야 효과적이라고 생각하지만, 이미 질문-문서 쌍이 유사하도록 학습된 모델에 MLM 학습을 하는 것은 효과적이지 않음으로 현재 적용할 수 있는 원문 한문, 번역 한글 쌍을 학습시켜보는 것. 또는 splade 논문의 학습 방법(**Sparse Encoder)**이 이번에(2025년6월 기준) sentence-transformers 프레임워크에 업데이트 됨. 이 방법이 “용어 및 개념의 표현 형식이 달라도 동일한 의미를 효과적으로 인지”하는데 도움이 될 것 같다. 실험해볼 예정.

2. FT1 (합성 질의 기반 학습)의 효과 가설: 실제 국가고시 문제 유형을 모방한 합성 질의를 통해 모델이 질의-문서 간의 관련성을 더 정교하게 학습하여, RAG 시스템의 검색 해결 능력이 향상될 것이다. ('학습 데이터 부족' 문제 해결 방안 중 하나)
3. 청킹 단계의 문맥 강화 (요약 및 메타데이터 추가) 가설: LLM으로 생성된 청크 요약 및 체질 메타데이터는 임베딩 모델이 문서 청크의 핵심 내용과 맥락을 더 풍부하게 이해하도록 돕고, 이는 특정 체질이나 질병에 대한 질의의 검색 정확도를 높일 것이다.
4. 하이브리드 검색 및 리랭킹의 시너지 가설: 파인튜닝된 임베딩 모델 기반의 Dense 검색과 한국어 형태소 기반의 BM25 검색을 조합한 하이브리드 검색은 검색 커버리지를 넓히고, 리랭킹은 초기 검색 결과의 순위 품질을 극대화하여 RAG 시스템의 전반적인 성능을 안정적이고 지속적으로 개선할 것이다.
5. 일반화 성능 가설: 위의 방법론들이 적용된 최적화된 RAG 시스템은, 학습에 사용된 의서 내의 문제뿐만 아니라 학습에 직접 사용되지 않은 다른 의서(상한론)의 국가고시 문제에서도 유의미한 정답률 향상을 보여, 임베딩 모델의 한의학 학습 방법론의 일반화 능력을 보여줄 것이다. 


동의수세보원과 상한론을 각각 원문과 번역본 모두 RAG에 제공. 이에 대한 가설

-고전 원전의 AI 활용 제시: 한의학연구들이 번역본 위주로 진행되면서 발생할수 있는 원문의 뉘앙스 및 다의성 손실 문제를 해결하고자 한다. 원문-번역 대조 학습과 다형식RAG 설계를 통해, AI가 번역의 한계를 넘어 지식의 원형인 한문 원전 자체를 이해하고 활용할 수 있는 가능성을 탐구한다. 고전의서의 디지털지식화에 대한 전략이 될 수 있음.

-파편화된 한의학 지식의 통합 및 확장 가능성 확인: 본 연구는 한의학 지식이 가진 다형성(한문/한글)과 다출처(다른 의서)의 특징을 AI가 어떻게 극복할 수 있는지 보여준다.원문-번역 대조 학습은 임베딩 모델에게 서로 다른 형태의 지식을 연결하는 역할을 학습시킨다. 향후 동의수세보원, 상한론,외에도 다른 문헌이나 현대 임상 데이터를 아우르는 통합적 '한의학 지식 허브' AI 시스템 구축의 한가지 가능성을 마련하고, 파편화된 지식의 사일로를 줄이는 가능성을 제시할 수 있다.
